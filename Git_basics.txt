Great question! Here's the simple workflow for committing files in the future:

## Step 1: Make Changes to Your Files

Edit, create, or modify any files (notebooks, Python scripts, etc.)

---

## Step 2: Check What Changed

```powershell
git status
```

This shows all modified/new files in red.

---

## Step 3: Stage the Files

Add the files you want to commit:

```powershell
git add .
```

(The `.` means "add all changes")

Or add specific files:

```powershell
git add filename.py
git add notebook.ipynb
```

---

## Step 4: Commit the Changes

```powershell
git commit -m "Your message describing what changed"
```

**Examples:**
```powershell
git commit -m "Update image preprocessing notebook"
git commit -m "Fix bug in data loading script"
git commit -m "Add new transfer learning implementation"
```

---

## Step 5: Push to GitHub

```powershell
git push origin main
```

---

## Complete Workflow Example

```powershell
# After editing your files...

git status                                  # See what changed
git add .                                   # Stage all changes
git commit -m "Update Lab 1 notebook"       # Commit with message
git push origin main                        # Push to GitHub
```

---

**That's it!** Repeat these 4 steps every time you want to save your work to GitHub. 🚀git
